# Bubble Space 課程審核快照 v11

更新日期：2026-08-12

## 全站基線

目前 roadmap 共 363 單元。v11 完成後的品質分布目標：

- 教科書級 QA：0
- 正式課綱／學習階段範圍已核對：33
- 舊人工內容待範圍複核：0
- 教材初稿：258
- 結構需重整：72

33 個 scope-verified 單元包含完整七年級五科：數學 9 章，國文／英文／自然／社會各 6 單元。

## 為何七年級五科仍不是 textbook-ready

「範圍核對」只回答：這些能力／內容在正式課綱的國中學習階段中是否合理、平台序列有沒有明顯漏置或跨級錯置。

教科書級還要另外通過：

- 先備能力與診斷；
- 核心概念鏈與常見迷思；
- 至少兩個不同完整示範；
- 足量真正科目題型與遷移題；
- 圖表／地圖／文本／音訊／實驗等素材；
- 答案與評分焦點人工核對；
- 無障礙與素材授權；
- 最終逐頁、逐題 UI 實際驗收。

因此 v11 仍刻意保持 `TEXTBOOK_READY_UNITS = 0`。

## 七年級國文

### 正式範圍

六個平台單元已對照國語文第四學習階段的：

- 字詞、文言字詞、句型與篇章；
- 敘事順序與描寫；
- 現代文本與文言／古典非韻文；
- 韻文與抒情；
- 說明、議論與資料；
- 寫作取材、組織、遣詞與修訂。

第四學習階段是國中七～九年級，因此平台六單元是七年級的教學序列，不宣稱國家規定每一項固定在某一學期。

### 本輪加厚

新增至少 12 個迷思／反例、6 個第二示範、24 個正式國文任務。所有新增閱讀材料與仿古短文／小詩皆為 Bubble Space 自寫，不搬出版社課文。

題型包含：語境詞義、標點效果、敘事順序、描寫效果、文言指涉／省略、詩歌意象、說明／論證證據、段落與寫作修訂。

### 尚缺

- 更長多文本閱讀與跨文本整合；
- 完整作文 rubric 與分段回饋；
- 更多現代／古典文本難度梯度；
- 最終人工作答與 UI 驗收。

## 七年級英文

### 正式範圍

六個平台生活溝通單元已對照英語文第四學習階段的聽、說、讀、寫及綜合應用。官方能力描述不等於全國固定「七年級文法章節順序」，因此平台依新生介紹、日常作息、資訊問答、規則、當下事件、過去事件安排語言情境。

### 本輪加厚

新增至少 12 個常見語言錯誤、6 個第二示範、24 個正式語境任務。材料包含學生資料卡、週行程、社團公告、場所規則、即時活動訊息與過去事件短訊息。

題目不只問「文法形式」，也要求從資料／公告找資訊、選擇自然回應、組織問句與寫短回答。

### 尚缺

- 真正 audio question schema；在音訊接好前，不把閱讀對話假稱聽力；
- 更多短文、簡訊／書信閱讀與寫作；
- 口語錄音／發音回饋架構；
- 字彙與句型難度需和平台 CEFR 練習系統分開校準；
- 最終人工語用校對與 UI 實測。

## 七年級社會

### 正式範圍

六個平台單元已分別對到臺灣地理、臺灣史與公民社會生活：

- 地理：位置／地形／海域；氣候水文、人口、產業、聚落與區域；問題探究與田野觀察。
- 歷史：史前、原住民族與海域交流；清帝國、日治、戰後；地方史與史料探究。
- 公民：家庭／團體；社會規範與文化變遷。

### 本輪加厚

新增至少 15 個迷思／證據限制、6 個第二示範、24 個正式社會科任務。

題型使用自足的經緯度／人口資料、史料式短摘、田野規劃、家庭／社團／校園規則案例與統治評價資料比較。

### 尚缺

- 正式 question-media schema 後加入真正地形圖、人口圖、歷史地圖、統計圖題；
- 更多史料來源批判與長資料組；
- 公民議題的多立場資料包與 rubric；
- 實際田野任務紀錄介面。

## 全站題目來源 audit

v11 新增 `scripts/audit-curriculum-source.mjs`，使用 TypeScript AST 掃描所有 `curriculum-*.ts/tsx` 來源中的明確題目物件。檢查：

- question ID 重複；
- `kind` 非 literal 或靠型別斷言修正；
- 選項少於 3、選項重複；
- `correctIndex` 非整數或超出選項數；
- 開放題缺 `sampleAnswer`；
- prompt／explanation 過短；
- 「根據下圖／觀察下圖」但沒有正式題目媒體機制的假素材題；
- 題目來源中的已知外語 token 污染；
- 大量完全重複的明確題幹。

這個 audit 是最低 source-quality gate，不取代真正的學科人工審核。
