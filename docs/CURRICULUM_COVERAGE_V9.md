# Bubble Space 課程覆蓋 v9

本文件追蹤「課程有沒有真的能學」而不是只追蹤畫面或單元名稱。

## 內容層級

- `reviewed`：已逐單元人工整理概念、示範、題目並通過 curriculum QA。
- `foundation`：依該年級／科目課程藍圖建立的基礎教學內容，能閱讀、看例子並完成自我檢核，但尚未宣稱完成逐題人工審閱。
- `planned`：只有課程路線，尚未提供教材內容；v9 目標是把這一層從正式課程中消除。

## v9 原則

1. 每個單元至少要有多個可讀懂的核心概念、具體例子、完整示範、練習與解析。
2. 不使用「看到一張圖」卻沒有圖的題目。
3. 圖像以學習需要決定：數學可用精確程式圖；自然／地理優先用來源與授權可追的教材圖；適合呈現過程時可用 GIF／動畫。
4. 題目頁不為裝飾強迫加圖，但看圖才能作答時，圖必須成為題目資料的一部分。
5. 來源範圍以十二年國教正式課綱為準；公開教育平台與教師資源只作章節粒度、教學順序與常見卡點參考，不直接複製教材文字或題目。

- 高一社會：目前六個單元。

國小一～六、國中七～九、高中一～三，國文／英文／數學／自然／社會，每一個 roadmap 單元至少提供 `foundation` 教材；原有 reviewed 單元繼續優先使用較深的人工內容。
