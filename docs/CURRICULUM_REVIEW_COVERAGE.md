# Bubble Space 正式課程內容審閱進度

> 原則：`build success` 不等於 `教材完成`。只有通過「範圍查核 → 核心概念 → 完整示範 → 自足題幹 → 答案/評分焦點 → 人工閱讀」的單元才標記 reviewed。

## 已審閱

### 七年級數學
- 上學期：正負數與數線
- 上學期：指數與科學記號
- 上學期：因數、倍數與分數運算
- 下學期：代數式
- 下學期：一元一次方程式
- 下學期：統計與資料

每單元目前至少包含：6–8 個核心概念、1 個完整示範、8 題自足練習/檢核。

> 下一次 roadmap 改版會再依 108 課綱粒度把七年級補入幾何符號、二元一次聯立方程式、直角坐標與二元一次方程式圖形、比例、一元一次不等式等現行課綱章節，避免舊版六大單元過度壓縮。

### 高一社會（目前平台共同入口）
- 上學期：地理－空間與區域分析
- 上學期：歷史－史料與時代
- 上學期：公民－社會與政治
- 下學期：地理－環境與人地關係
- 下學期：歷史－近現代變遷
- 下學期：公民－法律與權利

每單元目前至少包含：6–8 個核心概念、1 個完整情境示範、8 題自足練習/檢核。

## 尚未標記 reviewed

其餘國小一～六、國中八～九、高中二～三，以及其他科目，目前仍是課程 roadmap／範圍草案。

v5 開始，這些單元在正式課程頁會顯示「內容編修中」，不再使用舊版泛用模板冒充已完成教材。

## 審閱順序

1. 七～九年級：國文、英文、數學、自然、社會
2. 國小三～六年級：國文、英文、數學、自然、社會
3. 國小一～二年級：國文、數學＋生活課程映射；英文明確標記平台延伸
4. 高中一～三年級：先拆出數學 A/B、自然的物理/化學/生物/地科、社會的地理/歷史/公民，再進內容審閱

## QA Gate

每個單元必須確認：
- 學習範圍沒有超前或漏掉必要先備概念
- 頁數由概念與活動數決定，不用固定兩頁教學
- 題目需要的圖、表、文本、地圖、數據必須同頁提供
- 選擇題有唯一合理正解且干擾選項不是荒謬湊數
- 開放題有明確評分焦點與參考作答
- 解答真的回答題目，解析說明「為什麼」
- 同一單元六種 Lesson 不重複播放同一份教材
