# Bubble Space V20 教科書審稿規格

> 版本：V20.0  
> 建立日期：2026-08-18  
> 適用範圍：國文、英文、數學、自然科學、社會；國小至高中各正式課程路線。  
> 性質：Bubble Space 專案內部「教科書級內容審稿」標準，不等同國家教育研究院審定、出版社審稿或教育部認證。

---

## 1. 目的

V20 的目的不是再證明「453 個單元能產生內容」，而是逐單元確認：

1. 學生看到的內容是否正確、完整而不誤導。
2. 內容是否真的對應該年級、該學期、該領域的正式課綱。
3. 學生是否具備理解本頁所需的先備知識，若沒有，教材是否先補足。
4. 圖、表、數線、地圖、時間軸、結構圖、對話、文本視覺化等是否真正承載知識，而非裝飾。
5. 例題是否示範「如何思考」，而非只展示答案。
6. 題目是否真的測到本單元的知識與能力，答案與解析是否可獨立驗證。
7. 難度、文字量、步驟數與抽象程度是否符合該學習階段。
8. 最終文字、符號、圖表、譯名、資料來源與格式是否達到可出版的校對標準。

V20 採 **人工式逐頁／逐題審查為主，自動 audit 為輔**。任何自動 gate 都不能單獨把單元升級成 V20 教科書級。

## 2. 官方依據與來源優先序

V20 的課綱與教科用書判準以官方來源為最高優先：

1. **國家教育研究院：十二年國教領域／科目課程綱要**  
   https://www.naer.edu.tw/PageSyllabus?fid=177
2. **國家教育研究院：教科用書審查基準**  
   https://textbooks.naer.edu.tw/Benchmark.aspx
3. **教育部：國民小學及國民中學教科用書審定辦法**  
   https://edu.law.moe.gov.tw/LawContent.aspx?id=FL008948
4. **教育部：國民小學及國民中學教科用書審定會審查作業要點**  
   https://edu.law.moe.gov.tw/LawContent.aspx?id=GL002298
5. 國家教育研究院各領域最新課程手冊、教育部／國教院公告之名詞、譯名、度量衡、語音與其他正式規範。

官方教科用書審查基準包含：課程綱要、組織結構的統整／連貫／層次、文本內容的周延／平衡／正確／合宜、學習活動與評量、圖文表達，以及編寫體例。V20 將這些原則轉成可直接套用在 Bubble Space 數位教材的八大審查維度。

### 2.1 來源時效

- 課綱、法規、統計、制度、科技與科學資訊若可能變動，審稿時必須重新查核，不得只引用舊版專案內容。
- 社會科的法律、政策、人口、經濟、地理統計等，須記錄「資料年份／查核日期」。
- 自然科涉及當代分類、科學模型或安全規範時，須使用可靠且目前有效的來源。
- 若官方規範更新，舊 V20 通過紀錄須標記為 `review-stale`，重新確認受影響單元。

## 3. V20 審稿單位

審查不是只看「單元有沒有資料」。必須由大到小檢查：

`課程路線 → 學期 → 單元 → 學習步驟 → 頁面 → 概念／視覺 → 例題 → 題目 → 答案／解析`

每一個 V20 單元都必須有可追溯的審稿紀錄，至少包含：

- 年級、科目、學期、單元 ID、單元名稱。
- 官方課綱來源與學習內容／學習表現代碼。
- 必要先備知識。
- 本單元核心概念。
- 使用的主要視覺表達方式。
- 例題清單。
- 題目清單與答案查核結果。
- 發現問題、嚴重度、修正方式與複查結果。
- 審稿日期、審稿版本與審稿者／審稿方式。

## 4. 問題嚴重度：分數不能抵銷錯誤

### `P0 — Blocker`

任何一項存在，單元立即 **不通過 V20**：

- 事實、定義、公式、語法、史實、科學概念或答案錯誤。
- 客觀題無正確答案、複數合理答案卻只允許一個答案、答案鍵錯誤。
- 課綱年級／學習階段明顯錯置。
- 缺少理解或作答不可或缺的圖、表、文本、音訊、數據或前提。
- 圖解本身錯誤、比例／方向／標示造成錯誤概念。
- 例題推理錯誤或步驟導向錯誤結論。
- 危險的實驗操作、安全資訊錯誤。
- 重要法律、制度或當代資料已失效卻當成現況教學。
- 侵犯法律規範、來源／授權無法成立而又不可替換的核心素材。

### `P1 — Major`

不一定是「答案錯」，但會妨礙學生正確學習，修完前不得通過：

- 必要核心概念缺漏。
- 缺少先備橋接，學生無法合理理解下一步。
- 說法過度簡化到會形成錯誤概念。
- 例題與教學目標不對齊。
- 題庫大多只測表面辨識，沒有測到主要能力。
- 難度跨級、閱讀負荷或計算負荷明顯不合年級。
- 社會科爭議議題只呈現單一立場且把價值判斷當成唯一事實。

### `P2 — Minor`

內容仍可理解，但未達出版品質：

- 文字冗長、例子不夠自然、視覺標示可更清楚。
- 個別 distractor 診斷力偏弱。
- 局部順序、標題、圖說、提示文字可改善。
- 非關鍵格式或體例不一致。

### `P3 — Polish`

不影響正確性與學習，只是體驗優化：

- 排版、微文案、動畫節奏、次要視覺細節等。

**V20 通過條件：P0 = 0、P1 = 0。P2 必須全部有處置決策；若保留，需證明不影響學習與出版一致性。**

## 5. 評分方式

每一維度以 0–4 分評定：

- **4 — Publication-ready**：可直接進入出版級複查，沒有實質缺口。
- **3 — Pass**：教學上完整正確，只有極小修飾空間。
- **2 — Revise**：主體成立，但存在需要修改的品質缺口。
- **1 — Major revision**：核心設計有問題，需重寫／重做。
- **0 — Blocked**：存在重大錯誤或不可使用內容。

### 八大維度權重

| 維度 | 權重 |
|---|---:|
| A. 內容正確性 | 20% |
| B. 課綱對應 | 15% |
| C. 先備知識與學習連貫 | 10% |
| D. 視覺表達 | 15% |
| E. 例題品質 | 10% |
| F. 題目品質 | 15% |
| G. 難度與認知負荷 | 10% |
| H. 校對、體例與來源 | 5% |

### V20 單元通過門檻

單元只有同時符合下列條件才可標記 `v20-internal-ready`：

1. P0 = 0。
2. P1 = 0。
3. 八大維度每一項皆 ≥ 3。
4. 加權總分 ≥ 90 / 100。
5. 所有客觀題均已獨立作答／驗算；所有開放題均已檢查評分規準。
6. 課綱 mapping 有官方證據，不只是專案內自訂標籤。
7. 必要視覺、文本、音訊、數據皆實際存在並在桌機／手機可用。
8. 完成一次「從學生視角」由頭到尾的逐頁閱讀與作答。

**總分 90 分不能抵銷任何 P0／P1。**

# 6. 八大審查維度

## A. 內容正確性 — 20%

### A1. 共通標準

逐頁確認：

- 定義、概念、規則、公式、術語是否正確。
- 所有數字、計算、答案、圖表數據能否重新算出／驗證。
- 因果關係是否有足夠依據，沒有把相關性寫成因果。
- 是否有「為了簡單而寫成錯誤」的過度簡化。
- 限定條件、例外、適用範圍是否在需要時清楚交代。
- 最新資訊是否有時效問題。
- 同一概念跨頁、跨例題、跨題目是否前後一致。

### A2. 五科專屬查核

**國文**
- 原文、作者、作品、字詞、成語、語音、修辭與文體知識正確。
- 「可討論的詮釋」不可偽裝成唯一客觀事實。
- 文本解讀必須能回到原文證據。

**英文**
- 文法、字義、搭配、語序、時態、語用與情境自然。
- 例句不能只是文法可行，還要符合實際語境與適當 register。
- 聽力文字、畫面字幕、答案與音訊腳本一致。

**數學**
- 每個計算、方程、圖形條件、單位、符號、定理適用條件重新驗算。
- 不能用少數例子暗示尚未證明的一般結論。
- 圖形若非按比例，需避免讓比例成為推理依據。

**自然科學**
- 現象、模型、實驗、因果、單位、量測與科學術語正確。
- 清楚區分「模型／示意」與「真實比例／真實機制」。
- 實驗控制變因、操作變因、應變變因與觀察結論不可混淆。
- 涉及操作須檢查安全性。

**社會**
- 年代、人名、地名、疆域、制度、法律、統計與史實可追溯來源。
- 現行制度與法律需標示查核日期。
- 歷史敘述區分史實、推論與詮釋；爭議議題尊重多元證據與觀點。
- 地圖與統計不能以裁切、比例或分類方式造成誤導。

### A3. 通過證據

- 重要內容至少留下一筆可靠來源或獨立驗證紀錄。
- 客觀答案須「不看原答案先獨立解題」，再比對答案鍵。
- 計算題保留驗算；史實／法規／統計保留來源與日期。

---

## B. 課綱對應 — 15%

### B1. 每單元必填 mapping

- 官方課綱名稱與版本／來源。
- 教育階段與年級。
- 領域／科目／分科或路線。
- `learningPerformanceCodes`：學習表現代碼。
- `learningContentCodes`：學習內容代碼。
- 對應核心素養（若該單元確實承擔）。
- 單元中哪一頁／哪一活動實際提供上述學習證據。

### B2. 審查問題

- 單元是否放在正確年級、學習階段與科目路線。
- 課綱要求的核心內容是否完整，不因網站版型而漏掉。
- 是否自行加入超出該階段太多的內容。
- 延伸內容若保留，必須標成「延伸」，不能變成基礎學習必經門檻。
- 題目與評量是否真的在測對應學習表現，而不只測記憶。
- 同一課綱代碼是否被多個單元重複消耗，卻遺漏其他重要代碼。

### B3. 特殊結構

- 國小一、二年級正式的「生活課程」不可被專案導航上的自然／社會標籤誤稱為正式分科。
- 高中數學 A/B、甲/乙與自然、社會分科路線必須依正式課程結構審查，不得以單一五科名稱取代正式分流。

### B4. Blocker

- 課綱代碼無官方來源。
- 明顯跨年級錯置。
- 單元名稱看似對應課綱，實際內容沒有教到該學習重點。

---

## C. 先備知識與學習連貫 — 10%

### C1. 每單元先列「必要先備」

只列**若不會就無法合理理解本單元**的能力，不把所有舊知識都列入。

每一項先備需標示：

- `prerequisite`：需要會什麼。
- `source`：應在哪個先前單元／年級學到。
- `check`：如何快速確認學生已具備。
- `bridge`：若不具備，教材如何補一小段再繼續。

### C2. 連貫性標準

- 新概念建立在已介紹的概念上，不可使用尚未定義的術語解釋自己。
- 表徵順序合理：直觀／情境 → 表示 → 正式概念 → 應用，或符合該科適當的學習邏輯。
- 不能突然要求尚未練過的高階技能。
- 同一術語跨單元定義一致。
- 本單元結尾應能自然銜接下一個需要它的概念。

### C3. 審查方法

審稿者以「第一次學這個單元的學生」閱讀：每遇到一個必須已知的概念，就反查先前是否真的教過；查不到即記錄 `missing-prerequisite`。

---

## D. 視覺表達 — 15%

### D1. 原則

V20 不要求「每頁一定有圖」，而要求：**當知識包含空間、結構、關係、流程、時間、比較、數量、證據或語言結構時，應優先使用能承載該知識的視覺表達。**

圖不能只是裝飾。每一個主要視覺都必須回答：「拿掉這張圖，學生會少理解什麼？」若答案是「沒有」，它不算教材視覺。

### D2. 共通標準

- 圖解內容本身正確。
- 標籤、箭頭、軸、比例、圖例、單位、方向清楚。
- 圖與正文、例題、題目互相呼應。
- 不以顏色作為唯一資訊通道。
- 手機與桌機皆可讀，縮小後關鍵文字不消失。
- 圖說明確區分示意、非等比例、推測與實測。
- 外部圖／照片／地圖／數據圖記錄來源、授權、作者與必要 attribution。
- 有適當 alt text；互動圖需可用鍵盤或另有等價文字資訊。

### D3. 五科視覺語言

**國文**：篇章層次、段落關係、語句線索、敘事結構、修辭作用、語意／觀點關係。  
**英文**：對話情境、句型槽位、語意關係、時間順序、資訊差、聽讀線索；音訊屬核心媒體而非裝飾。  
**數學**：數線、面積／線段模型、幾何圖、座標、函數、統計圖、表格、比例與變化關係。  
**自然**：構造、系統、粒子模型、實驗裝置、控制變因、循環、因果／證據鏈、量測資料。  
**社會**：時間軸、地圖、空間分布、統計圖、制度關係、因果網絡、史料／證據比較與多觀點框架。

### D4. Blocker

- 圖中標示或數值錯誤。
- 圖比例或位置會讓學生形成錯誤概念。
- 題目要求「依圖」但圖不存在／資訊不足。
- 手機版裁掉作答所需的核心圖表資訊。

---

## E. 例題品質 — 10%

### E1. 最低結構

每個主要概念至少要有一個可完整跟讀的示範；每個單元整體至少包含：

1. **基礎例題**：只處理本單元核心概念，降低額外負荷。
2. **應用／變式例題**：換表徵、條件或情境，確認學生不是只記模板。

若單元有多個彼此獨立的核心概念，例題數量必須隨之增加，不得用兩題硬覆蓋所有概念。

### E2. 每個例題必須具備

- 完整、自足的情境或題目。
- 明確問題。
- 可追蹤的思考／推理步驟。
- 每個關鍵步驟說明「為什麼」，不是只有操作指令。
- 正確答案／結論。
- 驗算、回看原文、證據比對、單位檢查或其他該科適合的自我檢查方式。
- 至少指出一個可能出錯點，若該概念確有典型迷思。

### E3. 五科例題要求

- 國文：例題需引用實際文本證據，不以「因為這是重點」作解析。
- 英文：例句／對話必須自然且符合語境，並說明形式與語意的關係。
- 數學：不能跳掉學生最需要看的中間推理；單位與條件完整。
- 自然：從觀察／資料到結論的證據鏈完整，不把推論寫成直接觀察。
- 社會：史料、地圖、數據或制度題需指出證據來源與判讀方式。

### E4. 不通過案例

- 兩個例題只是換名字與數字。
- 步驟只有「套公式」「看關鍵字」。
- 先公布答案再反推理由。
- 例題難度遠高於後續練習，或遠低於評量。

---

## F. 題目品質 — 15%

### F1. 題目不是靠數量過關

V18 的 15+ 題結構只能作為題庫容量底線，V20 必須**逐題審查**。15 題中只要有 1 題 P0，單元仍不通過。

### F2. 每題共通標準

- 題目真的測本單元知識／能力，不是泛用「哪個學習方法最好」。
- 題幹自足；所需文本、圖、表、數據、音訊全部存在。
- 條件足夠且沒有不必要資訊造成非預期歧義。
- 客觀題正解唯一且可證明。
- 錯誤選項對應真實迷思／錯誤推理，不是荒謬填充選項。
- 選項長度、語氣、文法不能洩漏答案。
- 解析要解釋「為什麼正確／為什麼錯」，不能只重述答案。
- 開放題有可操作 rubric；rubric 對應題目要求，而非泛用模板。
- 不依賴前一題未公布的答案，除非明確設計成題組。
- 同單元無大量近義改寫、換數字式重複題。

### F3. 學習目標覆蓋

每個核心學習目標至少要有兩個彼此獨立的學習證據，例如：

- 一個 quick check／guided item。
- 一個 practice／assessment item。

不能 15 題都集中在最容易的一個概念。

### F4. 題型與科目

**國文**：需有完整文本／語句證據；合理的多重詮釋不應硬做唯一答案選擇題。  
**英文**：語境、閱讀、聽力、語言使用與適度產出；聽力題必須實際有音訊或可驗證腳本。  
**數學**：概念理解、基本運算、表徵、應用、推理／綜合，不可全是套公式。  
**自然**：現象、模型、實驗設計、資料判讀、證據與解釋。  
**社會**：史料、地圖、數據、制度、因果、多觀點／公共議題，不能只背 isolated facts。

### F5. 獨立驗題程序

審稿者驗題時：

1. **先遮住答案與解析自行作答。**
2. 記錄自己得到的答案與理由。
3. 再開答案鍵比對。
4. 檢查其他選項是否也可成立。
5. 檢查解析是否真的處理常見錯誤。

不允許只「閱讀原本答案覺得合理」。

---

## G. 難度與認知負荷 — 10%

### G1. 難度四級

- **D1 — 辨識／回憶**：辨認、讀取、直接回憶。
- **D2 — 單一概念應用**：一至數個明確步驟，直接使用剛學概念。
- **D3 — 推理／轉換／多步驟**：整合條件、換表徵、比較證據或多步推理。
- **D4 — 遷移／論證／探究**：新情境、開放論證、整合多概念或自主探究。

### G2. 流程難度原則

- 概念後 quick check：以 D1–D2 為主。
- Guided practice：D1–D2，必要時少量 D3。
- Independent practice：以 D2–D3 為主。
- Assessment：D2–D3 為主；只有課綱與年級合理時加入 D4。

不要求五科使用完全相同百分比；要求的是**難度有理由、逐步上升且符合課綱**。

### G3. 認知負荷檢查

- 新術語第一次出現前有沒有建立意思。
- 一頁是否同時引入太多新概念。
- 題目是否把閱讀難度、計算難度、陌生背景同時拉高，反而測不到目標概念。
- 長文本若是國文／英文的學習素材，可保留；若只是說明文字過長，應改成視覺、分段或漸進揭示。
- 例題到獨立練習不能突然跨越超過一個主要認知層級而沒有橋接。
- 同一單元需包含可讓一般學生成功開始的入口，也要有足夠挑戰確認真正理解。

### G4. 年級合宜性

審稿不能只問「成年人看得懂嗎」，而要問：

- 這個年級是否已具備所需詞彙與抽象能力？
- 生活情境是否符合學生可能理解的經驗？
- 句子長度、符號密度、資料量、步驟數是否合理？
- 題目需要的背景知識是否不小心超過本學科內容？

---

## H. 校對、體例與來源 — 5%

V20 最終複查以「準備出版」的標準執行。

### H1. 文字與符號

- 正體中文、臺灣用語一致。
- 錯字、漏字、多字、重複字：0。
- 標點符號、括號、引號、破折號、全半形一致。
- 數字、日期、百分比、年代格式一致。
- 數學符號、上下標、負號／減號、乘號、等號使用一致。
- 自然科單位與量值寫法一致，使用法定／學科慣用單位。
- 同一專有名詞不在不同頁任意換詞。

### H2. 名詞與譯名

- 外國人名、地名、專業術語已有官方公告譯名者，優先採公告內容。
- 必要時首次出現附原文，後續用法一致。
- 國語字音、注音若使用，須依適用的教育部公告規範。

### H3. 圖表與引用

- 圖號、表號、標題、圖例、單位、來源一致。
- 內文「如下圖／依表」必須真的有對應圖表且編號正確。
- 引用文本、照片、地圖、統計或外部素材保留來源與授權紀錄。
- 網址、音訊、媒體實際可開啟；不接受只存在資料欄位但前端未呈現。

### H4. 校對程序

至少兩輪：

1. **內容校對**：看正確性、邏輯、答案、圖文一致。
2. **純文字／體例校對**：刻意不重新思考內容，只抓字詞、符號、格式、編號、來源與前後一致性。

# 7. 跨維度必要標準

## 7.1 平衡、公正與法律

- 內容不得違反現行法律規範。
- 涉及群體、文化、性別、族群、國籍、身心狀況等，不使用不必要刻板印象。
- 爭議議題區分「可查證事實」與「價值／立場」。
- 社會科尤其需呈現足以理解議題的多元證據，不製造假平衡，也不把單一立場包裝成唯一事實。

## 7.2 自足性

學生不應為了看懂基礎教材而被迫離開網站搜尋缺失資訊。核心學習頁與題目需要的文本、圖表、數據、音訊或定義必須在當下可取得。

## 7.3 無障礙與裝置

- 桌機與手機均可完成完整學習流程。
- 字級調整不造成資訊消失／重疊。
- 按鈕、選項、圖表在小螢幕仍可操作。
- 不以 hover 作為唯一資訊來源。
- 重要資訊不只靠色彩區分。

# 8. 五科「不能共用模板取代」的審稿焦點

V20 共用同一套品質框架，但**不能用一個 generic template 判斷五科**。

| 科目 | 審稿時最需要守住的學科特性 |
|---|---|
| 國文 | 真實文本、上下文證據、篇章結構、語意與表達效果；允許有證據支持的合理詮釋差異 |
| 英文 | 語意先於形式、真實語境、自然用法、聽讀說寫的適當整合、音訊與文字一致 |
| 數學 | 定義與條件、表徵轉換、推理過程、驗算、符號精確、圖形不能誤導 |
| 自然 | 觀察與推論分離、證據鏈、模型限制、變因控制、量測與單位、實驗安全 |
| 社會 | 時間與空間脈絡、史料／資料來源、制度正確、統計時效、多元觀點與證據判讀 |

### 8.1 國小低年級生活課程附註

本網站若將一、二年級生活課程透過五科導航呈現，V20 審稿紀錄必須明確標示其正式課程來源為「生活課程」，不得因 UI 路由而宣稱它是正式自然或社會分科內容。

# 9. V20 審稿流程

## Stage 0 — 鎖定審稿版本

- 記錄 commit SHA／教材版本。
- 後續若內容改動，受影響頁面需重新複查。

## Stage 1 — 官方 scope mapping

- 先查正式課綱，再讀網站內容。
- 建立本單元學習內容／學習表現 mapping。
- 確認年級、學期、分科／路線。

## Stage 2 — 先備與教學順序

- 列 prerequisite。
- 從第一頁按順序讀，找出所有未先教卻直接使用的概念。

## Stage 3 — 逐頁內容＋視覺審稿

每頁回答：

1. 這頁唯一主要學習目的為何？
2. 文字是否正確且只保留必要資訊？
3. 視覺是否真的幫助理解？
4. 是否有可能建立錯誤概念？
5. 學生看完應該能做什麼？下一頁是否合理承接？

## Stage 4 — 逐例題盲解

- 不看答案先自行完成。
- 核對每一步與答案。
- 判斷是否真的示範思考，而非抄流程。

## Stage 5 — 逐題盲解

- 對所有正式題目重做一次。
- 檢查正解唯一性、distractor、解析、rubric、素材與難度。

## Stage 6 — 難度與整體節奏

- 標 D1–D4。
- 檢查同一單元由教到練的難度曲線。
- 檢查是否有不合理跳級或文字牆。

## Stage 7 — 出版校對

- 純文字／符號／圖號／資料來源第二輪校對。
- 手機、桌機實際走一次完整流程。

## Stage 8 — 複查與狀態判定

所有 P0/P1 修正後，重新從受影響前後頁讀一次，避免「修一處壞另一處」。最後才計算八維分數並決定狀態。

# 10. V20 狀態名稱與對外說法

### `v20-reviewing`
正在按本規格逐頁／逐題審查。

### `v20-internal-ready`
通過本文件全部硬 gate 與 90 分門檻；代表 Bubble Space 內部教科書級審稿完成。

### `v20-human-verified`
在 `v20-internal-ready` 之外，再有具相應學科／教育背景的真人審稿者完成獨立複查並留下紀錄。

### `officially-approved`
**專案不可自行使用。** 只有真的經適用的官方審定程序取得正式資格，才可使用等價宣稱。

因此：

- 自動 audit 全綠 ≠ `v20-internal-ready`。
- AI 逐頁審稿完成 ≠ `v20-human-verified`。
- `v20-human-verified` ≠ 國家教育研究院審定本。

# 11. 自動 Audit 可以做什麼、不能做什麼

### 可自動化

- 課綱 mapping 欄位是否存在。
- 先備欄位是否存在、是否形成循環 dependency。
- 題目數量、重複／近重複題。
- 客觀題 correctIndex 格式。
- 缺圖、缺 audio、缺 alt、缺來源欄位。
- placeholder、meta-strategy 題型、空泛 distractor。
- 圖表 DOM 是否 overflow、手機是否可操作。
- 體例 token、術語一致性、部分拼字／標點檢查。

### 不得只靠自動化判定

- 定義是否真的正確。
- 課綱內容是否真的被教會，而非只填了代碼。
- 圖解是否造成錯誤心智模型。
- 文學解讀是否有文本依據。
- 英文是否自然。
- 數學推理是否完整。
- 科學因果與模型是否正確。
- 社會史實、觀點與最新制度是否合理。
- 題目是否真正好題、難度是否合宜。

**V20 的核心原則：結構可自動檢查，教學品質必須實際閱讀、實際解題、實際查證。**

# 13. Definition of Done：真正可以說「V20 內部教科書級」

一個單元必須同時達成：

- [ ] 課綱逐碼對應完成且有官方來源。
- [ ] 必要先備知識有追溯與橋接。
- [ ] 所有核心概念逐頁人工式閱讀，沒有內容錯誤。
- [ ] 所有主要視覺逐一確認正確、必要、可理解、手機可讀。
- [ ] 每個主要概念有足夠示範；單元至少有基礎＋變式／應用例題。
- [ ] 所有正式題目逐題盲解，不只是抽樣。
- [ ] 客觀題答案唯一；開放題 rubric 可操作。
- [ ] 題目覆蓋所有核心學習目標，沒有大量模板／近重複題。
- [ ] 難度曲線符合該年級與教學流程。
- [ ] 完成第二輪文字、符號、圖表、來源與體例校對。
- [ ] P0 = 0、P1 = 0。
- [ ] 八維每項 ≥ 3，加權分數 ≥ 90。
- [ ] 實際桌機＋手機從頭學完一次。
- [ ] 審稿紀錄已存入 repo，可追溯到 commit。

只有全部勾選後，才可升級為 **`v20-internal-ready`**。
