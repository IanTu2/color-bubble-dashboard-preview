# Bubble Space 課程內容研究與品質基準（2026-08-11）

本文件記錄正式課程 v5 的內容重整原則。目的不是複製任何單一出版社或教育平台內容，而是以臺灣十二年國教課綱作範圍基準，並參考公開教育平台的課程拆分方式，建立 Bubble Space 自己的課程架構。

## 來源層級

1. 國家教育研究院／教育部十二年國民基本教育課程綱要：確認領域、學習階段與能力範圍。
2. 均一教育平台公開課程樹：參考章節粒度、觀念拆分、暖身／觀念／例題／練習／測驗的編排方式。
3. Bubble Space 自製教材：重新撰寫教學說明、例題、互動題與解析，不直接搬運他站教材。

## 這次確認到的舊版問題

- 舊 roadmap 每學期多數只有 3 個大單元，粒度明顯過粗。例如七年級數學公開課程實際可拆為整數運算與科學記號、因數分解與分數、一元一次方程式、幾何符號、聯立方程式、直角坐標、比例、不等式、統計等章節。
- 舊 Lesson 固定產生 2 段 bridge，因此 UI 看起來像「固定兩頁教學」；頁數不是由真實概念數決定。
- 舊 fallback 題曾出現「看到一張統計圖」但實際沒有提供統計圖的問題。這類缺素材題不得再進正式題庫。
- 舊版只驗證 build 與型別，沒有把「題幹自足、能否作答、答案能否判定、解釋是否真的對應教學內容」列為內容品質 gate。

## v5 教材 gate

每一個正式單元必須至少具備：

- 清楚列出 3–8 個真正的核心概念；不能只寫一段泛用 focus。
- 每個概念獨立成頁，頁數由概念數決定，不預設固定兩頁。
- 至少一個完整示範，示範必須有題目或素材、步驟、理由與答案。
- 練習題題幹必須自足；若需要圖、表、文本、地圖或資料，就必須同頁附上素材。
- 選擇題必須有可判定正解與解析；開放題必須有明確評分焦點與參考作答。
- 不以「請自己想一題」「依圖表而異」「依文本而異」當成沒有素材的正式練習。
- 一堂課不是固定題數；觀念密度高的單元必須增加概念頁、示範與練習。

## UI 原則

- WindowFrame 已經有一層標題列，正式課程內頁不再重複用大型 hero header。
- 課程內只保留單行 compact course bar：年級＋科目、單元、Lesson、頁數、進度、課程目錄。
- 主學習區一頁只做一件事：概念、圖解、示範、練習或總結。
- 內容回報入口保留在每一頁，未來 AI context 精確到 grade / subject / semester / unit / lesson / page。

## 已查核的公開課程結構（第一輪）

### 數學
- 國小一年級：100 以內的數、錢幣、加減、長度、時間、圖形、分類等。
- 國小二年級：1000 以內的數、加減直式、乘法、分裝平分、單位分數、長度、容量、時間、圖形、分類等。
- 國小三～六年級：依 108 課綱公開課程樹逐年擴展四則、分數小數、測量、幾何、比率、統計與機率。
- 國中七年級：整數與科學記號、因數分解與分數、一元一次方程式、幾何符號、聯立方程式、坐標、比例、不等式、統計。
- 國中八年級：乘法公式與多項式、平方根與畢氏定理、因式分解、一元二次方程式、統計、數列、線型函數、三角形、平行與四邊形。
- 國中九年級：比例線段與相似、圓、推理證明與三心、二次函數、統計與機率、立體幾何。
- 高中十年級：數與式、直線與圓、多項式函數、數列級數、數據分析、排列組合與機率、三角比。
- 高中十一年級：三角函數、指數與對數、平面向量、空間向量、空間中的平面與直線、條件機率與貝氏、矩陣、圓錐曲線等，後續 UI 要標示 A/B 分流差異。
- 高中十二年級：極限、微分、積分、複數、二次曲線、機率統計、線性規劃等，屬選修路線，不能假裝所有學校完全相同。

### 自然
- 國小以觀察、實驗與生活現象為核心；三年級起逐步進入植物、空氣、水、磁力、光、聲、熱、力、電、生態等。
- 國中應明確分出生物、理化、地科，不再使用一組「自然萬用模板」。
- 高中入口仍可叫自然，但內部必須再分物理、化學、生物、地球科學；地科例如地質、大氣、天文、海洋、永續。

### 社會
- 國小三年級起可由家庭／校園／家鄉，逐步到臺灣地理、歷史、政府、世界與全球議題。
- 國中必須把地理、歷史、公民三條線同時保留。七年級地理至少包括臺灣位置、地形、氣候水文、人口文化、產業與區域發展；公民再依家庭社區、社會、政治、法律、經濟、全球議題循序。
- 高中社會入口必須再細分地理、歷史、公民與社會，不應用「社會資料判讀」泛用頁面取代學科知識。

### 國語文
- 國小以識字、詞句、篇章理解、閱讀策略、口語與寫作能力累進。
- 國中／高中可參考公開課程中的文言、語法、現代文、詩詞、論說、閱讀素養等分類，但 Bubble Space 不直接重製受著作權保護的完整課文。

### 英語文
- 國小低年級視為平台延伸啟蒙；正式共同基準應從國小中年級起更謹慎標示。
- 課程不能只有單字；必須把語音、詞彙、句型、聽力、閱讀、對話與寫作放進完整語境。
- 國中依年級逐步加入時態、比較、情態、非限定／被動／完成式等語言功能；高中則增加篇章閱讀、學術詞彙、論述、聽記與長篇表達。

## 下一步

- 先把所有現有 track 的「三大單元」升級為較符合公開課程樹的年度單元結構。
- 再逐單元掛 researched unit profile（概念、常見迷思、示範、題型）。
- 未通過 reviewed gate 的單元不再假裝是完成教材；UI 應明確標示內容編修狀態。
